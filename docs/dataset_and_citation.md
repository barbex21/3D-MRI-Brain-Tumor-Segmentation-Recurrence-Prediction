# Dataset source and citation

This project uses the RHUH-GBM collection hosted by The Cancer Imaging Archive (TCIA).

- Official collection page: [RHUH-GBM at TCIA](https://www.cancerimagingarchive.net/collection/rhuh-gbm/)
- Dataset DOI: [10.7937/4545-c905](https://doi.org/10.7937/4545-c905)
- Dataset paper: [Cepeda et al., Data in Brief (2023)](https://doi.org/10.1016/j.dib.2023.109617)

## Required dataset citation

Cepeda, S., García-García, S., Arrese, I., Herrero, F., Escudero, T., Zamora, T., & Sarabia, R. (2023). *The Río Hortega University Hospital Glioblastoma dataset: a comprehensive collection of preoperative, early postoperative and recurrence MRI scans (RHUH-GBM)* [Dataset]. The Cancer Imaging Archive. https://doi.org/10.7937/4545-c905

## Access and reuse

Follow the current TCIA collection page and data usage policy when obtaining or using the data. Access conditions may differ between data products; the collection page identifies controlled-access image material and the terms attached to other downloads. Do not copy any MRI, segmentation, clinical table, or patient-level manifest into this repository.

A public dataset citation does not grant a license to this repository's code. No code license is declared here; obtain permission or confirm the applicable rights before reuse.
